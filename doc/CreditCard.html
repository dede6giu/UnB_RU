    class CreditCard

    Cartão de crédito usado na recarga (não tem tabela própria). Só confere o número (16 dígitos), o CVV (3 dígitos) e a validade (MM/AA, não vencida); nada do cartão é salvo.

    Attributes

    Validade no formato MM/AA e o código de segurança (CVV).

    expiry [RW]

    Validade no formato MM/AA e o código de segurança (CVV).

    number [R]

    Número do cartão, já sem espaços.

    Guarda o número do cartão tirando os espaços, porque quem digita costuma copiar o número com os espaços do cartão.

    Recebe o número como veio do formulário (value). Não retorna valor útil; o efeito é guardar o número limpo no objeto.

def expiry_not_in_the_past
  return if errors.include?(:expiry)

  month, year = expiry.split("/").map(&:to_i)
  last_valid_day = Date.new(2000 + year, month, 1).end_of_month
  errors.add(:expiry, "está vencida") if last_valid_day < Date.current
end

    Validação da validade: o cartão vale até o último dia do mês de MM/AA. Só roda com o formato já válido.

    Não recebe argumentos nem retorna valor útil. Se a validade já passou, adiciona o erro “está vencida”.
