    class RestaurantsController

    Controller para o model Restaurant. Ações CRUD são disponíveis para apenas usuários atualmente autenticados como admins, enquanto Read é permitido para qualquer usuário.

def create
  @restaurant = Restaurant.new(restaurant_params)

  if @restaurant.save
    redirect_to restaurants_path, notice: "Restaurante criado com sucesso."
  else
    render :new, status: :unprocessable_content
  end
end

    POST /admin/restaurants ou /admin/restaurants.json

    Chamado com POST, na página de new do restaurant. Salva um novo restaurant na database se nenhum erro for encontrado nas verificações.

    No caso de sucesso, redireciona para RestaurantsController#index.

    No caso de falha, retorna os parâmetros necessários para exibir a falha em RestaurantsController#new, e nada é alterado na database.

def destroy
  @restaurant.destroy!
  redirect_to restaurants_path, notice: "Restaurante destruído com sucesso.", status: :see_other
rescue ActiveRecord::RecordNotDestroyed
  render :edit, status: :unprocessable_content
end

    DELETE /admin/restaurants/1 or /admin/restaurants/1.json

    Chamado após confirmar deleção na página de edição. Apaga o restaurant na database se nenhum erro for encontrado nas verificações.

    No caso de sucesso, redireciona para RestaurantsController#index. O restaurant não existe mais no registro.

    No caso de falha, retorna os parâmetros necessários para exibir a falha em RestaurantsController#edit, e nada é alterado na database.

def update
  if @restaurant.update(restaurant_params)
    redirect_to restaurants_path, notice: "Restaurante atualizado com sucesso.", status: :see_other
  else
    @restaurant.reload
    render :edit, status: :unprocessable_content
  end
end

    PATCH/PUT /admin/restaurants/1 or /admin/restaurants/1.json

    Chamado com PATCH/PUT, na página de edit do restaurant. Atualiza o restaurant :id na database se nenhum erro for encontrado nas verificações.

    No caso de sucesso, redireciona para RestaurantsController#index.

    No caso de falha, retorna os parâmetros necessários para exibir a falha em RestaurantsController#edit, e nada é alterado na database.
